# Portfolio capture checklist

After stable hosted deployment, capture:

- Dashboard with simulated-data and partial-score disclosures.
- Device List and Device Details historical range.
- Alert acknowledgement/investigation/resolution workflow using private access.
- Accessible Topology graph and list.
- Reports, CSV behavior, and Settings role matrix.
- Architecture diagram showing Browser → one Web → PostgreSQL and one Worker.
- 60–120 second video: disclosure, Viewer login, dashboard, devices/history,
  alerts, topology, reports/settings, and known limitations.
- Verified live URL, repository URL, exact test totals, and hosted performance.

Exclude real credentials, cookies, database details, private-role login copy,
fabricated scores, and unverified claims. Blur or omit sensitive operator UI.
