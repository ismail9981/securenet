# SecureNet portfolio case study — draft

SecureNet is a deterministic simulated Network Monitoring Center built as a
modular Next.js/TypeScript application with PostgreSQL, Prisma, a separate
simulation worker, REST recovery, and authenticated SSE.

The case study should explain the problem, architecture boundaries, safe Demo
identity/RBAC, history-preserving data model, alert lifecycle, accessible
topology, deterministic simulation, reports/settings, testing strategy, and
single-instance Render design. It must prominently label all data as simulated
and list the accepted limitations.

Pending after approved deployment: live URL, repository URL, actual screenshots,
hosted performance results, isolated restore proof, exact final test totals, and
the final Demo video link. No placeholder is evidence.
